How to get your Xero credentials
  1. Go to Xero Developer Portal
  2. Create a new app or select an existing one
  3. Copy the Client ID from the Configuration tab
  4. Click "Generate a secret" and copy it
  5. Enter both above and click "Connect to Xero"
