SpEL Expression Help

Write a condition that returns true or false.

Available Variables

  • #message – the error message (String)
  • #amount – transaction amount (BigDecimal)
  • #customerEmail – customer email (String)
  • #merchantId – merchant ID (Long)
  • #description – invoice description (String)

Examples

#message.contains("timeout") → matches if error message contains "timeout"
#amount > 1000 → matches if amount > 1000
#description.toLowerCase().contains("urgent") → case-insensitive match

Operators

&& (AND), || (OR), ! (NOT), ==, !=, <, >, <=, >=
